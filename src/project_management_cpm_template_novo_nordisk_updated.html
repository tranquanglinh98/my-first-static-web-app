Edit dependencies

Dependencies are maintained on leaf tasks. Add one or more predecessor tasks, relationship type, and optional lag in calendar days.

FSFinish-to-start: successor starts after predecessor finishes. SSStart-to-start: successor starts after predecessor starts. FFFinish-to-finish: successor finishes after predecessor finishes. SFStart-to-finish: successor finishes after predecessor starts.

Using the project template

This file is a self-contained project planner. It works directly in a modern browser and stores changes locally.

Build the WBS

Use ＋ Add task for a top-level task. Use the small plus beside a task name to create a subtask. Up to five WBS levels are supported. Drag the dotted row handle to reorder: drop above or below another row, or drop into an existing summary task.

Plan and baseline

Plan dates are the baseline. The CPM engine schedules leaf tasks from project start, durations, dependencies, lags, and manually pinned plan starts. Dates display as dd-mm-yyyy. Type a date directly or click the calendar button. Editing a plan start or dragging a Gantt bar pins that task to the selected date. Use the circular-arrow button beside a pinned date to return it to automatic scheduling.

Actuals and delay tags

Enter actual start and finish dates on leaf tasks. Start and finish gaps compare actual dates with plan. The status column automatically adds Late start or Late finish when dates slip or when an unfinished task is overdue.

Dependencies and critical path

Click the dependency cell of any leaf task. The tool supports FS, SS, FF, and SF relationships with positive or negative lag. The CPM engine recalculates total float automatically. Zero-float tasks and driving dependency links are highlighted in red.

Gantt interaction

Drag a leaf-task bar horizontally to change its constrained plan start. Drag the right edge to change duration. Use Day, Week, or Month zoom and the Today button. Filters apply to both the table and Gantt chart.

Columns and data

Drag the handle below the filter controls to resize that area. Drag a column header to reorder it, drag its right edge to resize it, or drag a row boundary in either the table or Gantt chart to resize that task row. Long task names wrap within the Task name column and rows auto-fit unless you set a manual height. Double-click any resize handle to restore its automatic/default size.

Open Columns to show or hide individual fields or use Compact/Full presets. Export creates a JSON backup; Import restores one. Reset Sample replaces the current project after confirmation.
